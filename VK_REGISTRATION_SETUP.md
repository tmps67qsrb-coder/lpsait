# Подтверждение регистрации через VK

Ветка `codex/vk-registration-confirmation` содержит интеграцию сайта с ботом сообщества VK. Регистрация создаёт временную заявку, открывает `https://vk.me/<сообщество>?ref=<одноразовый-параметр>` и завершает её после нажатия пользователем кнопки «Начать».

## Настройка сообщества VK

1. Включите сообщения сообщества и создайте ключ доступа сообщества с разрешением на сообщения.
2. Откройте в сообществе «Работа с API» → «Callback API», добавьте сервер и включите событие `message_new`.
3. Адрес Callback API: `https://<домен-сайта>/api/vk-callback`.
4. Сохраните строку подтверждения и секретный ключ Callback API.
5. В поле короткого адреса сообщества укажите slug из `vk.me/<slug>`.
6. На странице настройки Callback API введите адрес, строку подтверждения и секретный ключ; дождитесь успешной проверки VK.

## Переменные Netlify

Задайте для production/deploy preview:

- `VK_COMMUNITY_SLUG` — короткий адрес сообщества без `vk.me/`.
- `VK_COMMUNITY_ID` — числовой ID сообщества (для указанного сообщества `241031950`).
- `VK_CALLBACK_SECRET` — секрет Callback API, заданный в настройках VK.
- `VK_CONFIRMATION_TOKEN` — строка подтверждения из настроек Callback API.
- `VOTE_SECRET` — постоянный секрет проекта длиной не менее 32 байт.

После добавления переменных запустите новый deploy. Существующие redirect rules направят `/api/vk-callback` в Netlify Function.

## Проверка потока

1. Откройте регистрацию на deploy-версии сайта и создайте тестовую заявку с отдельным номером.
2. Нажмите «Открыть бота ВКонтакте», затем «Начать».
3. Вернитесь на сайт. Он опрашивает статус заявки и после подтверждения завершает регистрацию и открывает личный кабинет.
4. Проверьте, что обычный посетитель не регистрируется без нажатия «Начать».

Одноразовая ссылка действует 10 минут. Она подтверждает контроль VK-аккаунта, а не личность или номер телефона пользователя.
